# 图片质量检查清单

## 模式A 生成后检查规则

两张图片生成后，**对 Route A 和 Route B 分别逐项检查**，发现问题自动修正提示词并重新生成，最多迭代 3 次。

**每张图片的检查清单（Route A / Route B 各执行一遍）：**

| # | 检查项 | 判定标准 |
|---|--------|----------|
| 1 | 禁止元素 | 画面中是否出现宽高比数字、结构描述词（「区块」「面板」「主角区」）、格式符号（【】《》） |
| 2 | 文字可读性 | 所有中文文字是否完整可读，无截断、无重叠、无占位乱码 |
| 3 | 语言一致性 | 画面文字是否全为中文，有无被翻译为英文的标签 |
| 4 | 箭头方向 | 若有箭头，是否全部朝右（→），无左向（←） |
| 5 | Route B 专项 | 画面中是否出现风格名称词汇（如「OLED」「Dark Mode」等）作为可见文字 |
| 6 | 构图与比例 | 画面内容是否符合用户选定比例的构图适配描述 |

**检查后的处理（⚠️ 检查通过前不输出图片）：**
- **通过**：将该图片加入最终输出队列
- **发现问题**：在提示词的禁止元素块末尾追加针对该问题的具体禁止条目，**静默重新生成**（不输出中间结果，不影响另一张），重复检查
- **迭代上限**：单张图片最多重试 3 次，仍有问题则加入队列并标注「⚠️ 存在已知问题：{描述}」
- **两张均通过（或达到上限）后，统一输出**
