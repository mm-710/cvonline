## 核心原则

- **同时输出两段提示词**：Route A + Route B，供用户选择
- **比例与用户确认**：先推荐比例，用户确认后再使用，A/B 统一比例
- **不预设行业规则/配色/字体/布局**：这些约束会限制生图效果，交由模型自由发挥
- **禁止元素块按内容类型动态调整**：文字内容型与纯视觉主体型使用不同的禁止元素块
- **Style token 控制**：风格句中的描述词总数 ≤ 7个，过多会导致输出不稳定

## Step 0 — 判断图片类型

根据用户输入的内容特征，判断图片类型，填入提示词第一行的 `{图片类型}` 占位符，并选择对应的**质量声明**。

| 用户意图信号 | 图片类型词（中文） | 质量声明 |
|---|---|---|
| 数据/分析/报告/多要点并列 | 信息图 | 所有文字清晰可读，无占位文字，无乱码 |
| 宣告/主张/情感/单一主题 | 海报 | 印刷级视觉质量，高对比度，视觉冲击力强 |
| 场景/故事/人物/空间描述 | 插画 | 线条清晰，色彩饱和，细节丰富 |
| 界面/应用/仪表板/截图 | UI截图 | 高保真界面，组件清晰，文字可读 |
| 产品/物品/展示图 | 产品图 | 商业摄影质量，主体清晰，背景干净 |
| 人物/肖像/摄影风格 | 摄影图 | 超写实，锐利对焦，专业摄影质感 |
| 贴纸/表情/图标 | 贴纸图 | 粗黑描边，扁平色块，白色边框，无背景 |
| 图案/纹理/平铺设计 | 图案 | 无缝平铺，图案清晰，适合印刷/数字使用 |
| 像素/复古/游戏风格 | 像素艺术 | 像素清晰，无抗锯齿，色板有限且一致 |
| 等距/几何/技术插画 | 等距插画 | 30-45度标准视角，线条精确，阴影统一 |
| 概念艺术/科幻/奇幻场景/游戏道具 | 概念艺术 | 电影级画面质量，氛围深邃，细节丰富 |
| 默认/无法判断 | 信息图 | 所有文字清晰可读，无占位文字 |

**同时判断内容类型（影响禁止元素块的选择）：**
- **文字内容型**：用户输入的是文字信息、数据、主张（信息图/海报等）→ 使用文字型禁止元素块
- **纯视觉主体型**：用户描述的是一个视觉主体（道具/人物/产品/场景）→ 使用视觉型禁止元素块

## Step 1 — 推荐比例并与用户确认

根据图片类型和内容量，先给出推荐比例，**向用户确认后再使用**。

**推荐逻辑：**

| 内容特征 | 推荐比例 |
|---|---|
| 多模块并列（3个+要点、有数字/数据） | `9:16` |
| 单一主题 / 情绪宣告 / 一个核心主张 | `1:1` |
| 流程图 / 左右对比 / 横向叙事 | `16:9` |
| 封面图 / 社交传播卡片 / 贴纸 | `3:4` |
| 人物肖像 / 产品主图 / 单体竖型物体 | `4:5` |
| 超宽场景 / 电影概念图 | `21:9` |

**询问用户的标准话术：**
> 根据内容，我推荐使用 `{推荐比例}` 比例（{推荐原因，1句话}）。你也可以选择其他比例：
> - `9:16` — 竖版长图，适合信息量多、手机阅读
> - `1:1` — 正方形，适合单一主题、社交媒体
> - `16:9` — 横版宽图，适合流程/对比/演示
> - `3:4` — 竖版卡片，适合封面/社交传播
> - `4:5` — 竖版人像，适合肖像/单体主图
> - `21:9` — 超宽横图，适合电影感/全景场景
>
> 请确认比例，或直接告诉我你想用哪种。

**用户确认比例后：**
根据用户选择的比例，在叙事段落中融入对应的**构图适配描述**（见下方构图适配规则）。

### 比例 × 构图适配规则

| 比例 | 构图特征 | 叙事段落中可融入的构图描述 |
|---|---|---|
| `9:16` | 纵向多信息层叠 | 从上到下分层展开，信息由疏到密 |
| `1:1` | 中心聚焦，四边留白 | 核心主体居中，四周大面积留白强化视觉焦点 |
| `16:9` | 横向展开，左右叙事 | 画面横向铺开，左右分区形成视觉对话 |
| `3:4` | 竖版封面感，上主下文 | 上部视觉主体，下部文字区域自然收尾 |
| `4:5` | 微竖，主体突出 | 主体垂直居中，上下各留适度空间 |
| `21:9` | 超宽全景，左中右三区 | 画面极宽，主体居中，两侧延伸环境氛围 |

## Step 2 — 输出 Route A（叙事流）

**规则：**
- 将用户原始文本改写为**连续叙事段落**
- 保留所有数字、百分比、说明文字
- 去除 markdown 符号（`#`、`**`、`-` 等）
- 不分区块标题，自然流动
- 若内容有明确的 Subject（主体）、Action（动作）、Location（场景）信号，自然融入叙事，不单独列出
- 末尾加一句**情感金句**（8–20字），直接融入正文，不加任何标签
- 不指定任何风格、配色、字体、布局
- **纯视觉主体型**：叙事段落改为对主体的材质/光线/氛围/比例感的细节描述

**模板：**

```
生成一张{比例}的{图片类型}，主题为"{从内容提炼的主题}"。

{连续叙事段落，自然融入主体/动作/场景信号，并融入比例对应的构图描述}

{情感金句}

质量要求：{对应图片类型的质量声明}

{禁止元素块（根据内容类型选择，见下方）}
```

### 禁止元素块 — 文字内容型

```
禁止元素——严格执行：
- 所有文字必须为中文，禁止将任何中文标签翻译为英文
- 禁止出现9:16、16:9等宽高比数字标注
- 禁止出现【】《》等格式符号装饰标题
- 禁止出现无说明文字的孤立数字刻度（0、2000等）
- 禁止出现「区块」「面板」「主角区」等结构描述词
- 禁止出现px/pt等技术单位标注
- 禁止文字截断、重叠或出现无意义占位文字
- 禁止出现←箭头（时间方向必须朝右→）
```

### 禁止元素块 — 纯视觉主体型

```
禁止元素——严格执行：
- 禁止在画面上叠加任何文字标注或说明文字
- 禁止出现9:16、16:9等宽高比数字标注
- 禁止出现「区块」「面板」等结构描述词
- 禁止出现px/pt等技术单位标注
- 禁止主体模糊或细节缺失
- 禁止出现多个主体，画面焦点只有{主体名称}
```

## Step 3 — 输出 Route B（风格锚点）

**与 Route A 完全相同，唯一区别是在叙事段落前增加一行「视觉风格：…」。**

> ⚠️ **词库使用边界**：`Prompt-Reference.md` Part 7 / Part 8 中的所有场景词库（写实摄影、游戏概念艺术、食物摄影、建筑、自然等）**仅用于生成本步骤的「视觉风格：」行**，绝不能将这些技术参数词汇（镜头参数、材质名称、光线描述等）写入 Route A 的叙事段落。Route A 不含任何风格约束。

### 风格句生成规则（词库为主 + 自动推断为辅）

**① 判断是否为特殊类型（优先）**

以下类型有固定风格写法，**直接使用，跳过词库匹配**：

| 图片类型 | 固定风格句 |
|---|---|
| 贴纸图 | `thick black outline, flat colors, white border, no background, high contrast, simple shapes` |
| 图案 | `seamless pattern, repeat tile, {密度: dense/airy}, suitable for {textile/wallpaper/packaging}` |
| 像素艺术 | `pixel art, 16-bit color palette, crisp pixels, no anti-aliasing` |
| 等距插画 | `isometric illustration, 30-45 degree angle, flat cel shading, soft drop shadow, clean background` |

**② 从内容语义提取调性信号**

读取用户文本，判断：
- 行业领域（AI/科技/医疗/教育/消费…）
- 情感基调（前瞻/温暖/严肃/活力/宣告…）
- 内容性质（数据报告/价值主张/故事叙述/流程说明/视觉主体…）
- 是否有摄影风格需求（人物/产品/场景的写实描述）

**③ 从 `Prompt-Reference.md` Part 3 词库匹配风格**

根据调性信号，在 Part 3 的 84 种风格中匹配最接近的一条，取其 `Gemini Prompt Phrase` 字段作为主体句。

快速参考（高频场景）：

| 调性信号 | 推荐风格 | Gemini Prompt Phrase |
|---|---|---|
| AI + 科技 + 前瞻 | Dark Mode (OLED) | `OLED纯黑背景+霓虹彩色点缀+高对比文字，深夜科技感` |
| AI + 企业级 + 克制 | AI-Native UI | `极简交互界面+AI紫色点缀，专为AI驱动设计的原生界面感，留白充分，克制有力` |
| 变革 + 能量 + 梦幻 | Aurora UI | `渐变极光背景+流动色彩融合+梦幻光晕，仿佛北极光在屏幕上流动的视觉体验` |
| 宣告 + 极简 + 直接 | Minimalism & Swiss Style | `纯白背景+极细无衬线字体+大量留白，层次清晰，干净克制的极简主义风格` |
| 数据 + 商务 + 专业 | Glassmorphism | `半透明磨砂玻璃卡片+渐变紫蓝背景+柔和光晕，高端现代的视觉质感` |
| 活力 + 年轻 + 创意 | Vibrant & Block-based | `明快几何色块+高饱和撞色+活泼大字，清爽利落的互联网插图风格` |
| 温暖 + 亲切 + 人文 | Organic Biophilic | `自然绿褐色系+有机曲线形态+木石质感，亲近自然的生态设计风格` |
| 人物 + 写实摄影 | Portrait Photography | `soft studio lighting, 85mm portrait lens, shallow depth of field, professional photography` |
| 产品 + 商业摄影 | Product Photography | `studio-lit product shot, clean background, sharp focus on product detail, commercial photography quality` |
| 概念 + 科幻 + 电影感 + 游戏道具 | Cinematic Concept Art | `cinematic concept art, dramatic lighting, atmospheric depth, film production quality` |
| 水彩 + 手绘 + 艺术 | Watercolor Illustration | `watercolor illustration, soft brush strokes, painterly texture, light paper grain` |
| 扁平 + 几何 + 现代 | Flat Design Vector | `flat design vector illustration, bold outlines, limited color palette, clean geometric shapes` |

**④ 自动推断场景意象（可选点缀）**

从内容中提取一个具体场景意象、动态感或构图描述，例如：
- 升级/转型内容 → `核心词从黑暗中发光浮现`
- 宣告/公告内容 → `像一张正式宣告的告示牌`
- 数据/报告内容 → `数字从背景中清晰浮现`
- 极简/单主题 → `居中构图，大面积留白`
- 游戏道具/单体主体 → `主体悬浮于黑暗中央，光源从内部溢出`
- 场景/叙事内容 → `{描述画面中正在发生的具体动作或氛围}`

**⑤ 判断是否追加，控制 token 总数**

- 若意象与词库句**不重复、能补充画面感** → 追加到词库句末尾
- 若与词库句语义**重叠或无增益** → 直接用词库原句，不加
- **检查总 token 数：风格句中描述词 ≤ 7个**，超出则删减最弱的词

**风格句格式：**
```
{词库 Gemini Prompt Phrase}，{自动推断意象（可选）}
```

**模板：**

```
生成一张{比例}的{图片类型}，主题为"{主题}"。

视觉风格：{风格句（≤7个描述词）}

{与 Route A 完全相同的叙事段落，含构图适配描述}

{情感金句}

质量要求：{对应图片类型的质量声明}

{禁止元素块（根据内容类型选择）}
（Route B 额外追加：禁止出现风格名称词汇作为图片中的可见文字）
```

## 完整示例二：纯视觉主体型（概念艺术）

**用户输入：**
> 生成一张游戏手杖，电影级质感

**Step 0：** 游戏道具/概念艺术（纯视觉主体型），质量声明：`电影级画面质量，氛围深邃，细节丰富`

**Step 1：** 推荐 `4:5`（单体竖型物体，主体垂直居中，上下各留适度空间），用户确认后使用。构图适配：主体垂直居中，上下各留适度空间。

**Step 3 风格匹配：**
- 信号：游戏道具 + 电影质感 → 匹配 `Cinematic Concept Art`
- 词库句：`cinematic concept art, dramatic lighting, atmospheric depth, film production quality`
- 自动推断：`手杖悬浮于黑暗中央，光源从内部溢出`（有亮点，追加）
- token 检查：6个，符合 ≤7 规则

