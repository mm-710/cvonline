# 意图识别信号词参考

## 信息图意图信号词（最高优先级，直接路由）

以下信号词出现时，**不走本 skill 流程**，直接告知用户推荐使用 `designai-Infographic-image` 专业信息图 skill：

- **明确词**：「信息图」「infographic」「数据可视化图」「数据图表」「统计图」
- **组合词**：「数据 + 做成图」「报告 + 生成图」「把数据可视化」
- **场景词**：「多要点对比图」「时间轴图」「流程说明图（有数据/文字内容）」「KPI 展示图」「年度总结图」

**路由话术（直接回复用户）**：
```
你的需求是生成信息图，建议使用专业的 **designai-Infographic-image** skill，它专为信息图设计，支持多种图表类型和排版风格，效果更好。

请直接告诉我：使用 designai-Infographic-image skill 来帮你生成。
```

> ⚠️ 若用户明确表示「不用，就用当前 skill 生成」，则降级走模式A（文生图）继续处理。

## 修改已生成图片的意图信号词

以下信号词出现时，即使用户没有附件，也判定为**修改图片意图**，自动取对话历史中最近生成的图片 URL 作为参考图，走模式B：

- **颜色修改**：「换成X色」「改成X色」「以X色为主」「变成X颜色」
- **风格修改**：「换成X风格」「改成X风格」「这个风格改成」「变成X感觉」
- **内容修改**：「把X改成Y」「去掉X」「加上X」「换掉X」「删除X」
- **参考前图**：「这张图」「这个图片」「上面那张」「Route A/B」「刚才生成的」+ 修改动词
- **模糊指示词 + 修改动词**：「这个」「那个」「它」+ 「换」「改」「调整」「修改」「变」

> ⚠️ **注意**：若对话历史中无可用图片 URL，则降级为模式A（文生图），并在提示词中融入修改方向。
