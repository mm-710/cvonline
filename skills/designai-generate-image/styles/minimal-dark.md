# 极简深色风格 (Minimal Dark)

## 风格ID
minimal-dark

## 风格描述
极简主义深色风格，灵感来源于 Terminal、VS Code 深色主题、GitHub Dark Mode。强调信息密度和可读性，去除所有装饰性元素。

## 视觉特点
- 纯黑或深灰背景 (#000000 或 #0d1117)
- 白色主文字，灰色辅助文字
- 细边框分隔，无阴影
- 等宽字体风格
- 极高的信息密度

## 配色方案
- 背景：#000000 或 #0d1117
- 主文字：#ffffff
- 辅助文字：#8b949e
- 边框：#30363d
- 强调色：#58a6ff（蓝色）、#3fb950（绿色）、#f85149（红色）

## 基础提示词

```
生成一张极简主义深色风格的16:9技术架构图。

视觉风格：
- 纯黑背景(#000000)，无任何渐变或纹理
- 白色主文字，灰色辅助文字
- 使用细边框(1px)分隔内容区域
- 类似终端或代码编辑器的视觉感受
- 等宽字体风格，信息密集

配色：
- 强调色使用蓝色(#58a6ff)标记重点
- 成功/正向使用绿色(#3fb950)
- 警示/重点使用红色(#f85149)

禁止元素：
- 禁止任何渐变背景
- 禁止任何3D效果
- 禁止任何光效或发光
- 禁止任何装饰性图案
- 禁止圆角超过4px
```

## 适用场景
- 技术文档配图
- 代码架构说明
- 系统设计图
- 开发者向的演示
