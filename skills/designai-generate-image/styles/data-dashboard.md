# 数据可视化风格 (Data Dashboard)

## 风格ID
data-dashboard

## 风格描述
数据仪表盘风格，适用于数据汇报、KPI展示、业务分析。强调数据的清晰呈现和专业的可视化效果。

## 视觉特点
- 深色背景，减少视觉疲劳
- 清晰的数据卡片布局
- 发光的数据图表
- 实时数据仪表盘感觉
- 科技感和专业感并存

## 配色方案
- 背景：#0d1117 或 #1e1e2e
- 主文字：#ffffff
- 辅助文字：#8b949e
- 卡片背景：#21262d
- 数据正向：#3fb950（绿色）
- 数据负向：#f85149（红色）
- 主强调色：#58a6ff（蓝色）
- 图表渐变：#58a6ff → #a371f7

## 基础提示词

```
生成一张数据仪表盘风格的16:9图片。

视觉风格：
- 深色背景(#0d1117)
- 多个数据卡片网格布局
- 数据图表带有发光效果
- 类似 Grafana、Datadog 仪表盘的视觉感受
- 科技感和专业感

配色：
- 正向数据使用绿色(#3fb950)带向上箭头
- 负向数据使用红色(#f85149)带向下箭头
- 图表使用蓝紫渐变
- 卡片使用深灰色背景

元素风格：
- 大数字突出显示关键指标
- 迷你图表（折线图、柱状图）
- 百分比变化标签
- 卡片有微妙的边框发光

数据展示：
- KPI卡片排列整齐
- 每个卡片包含：指标名称、数值、变化趋势
- 底部可以有详细的图表

禁止元素：
- 禁止3D物体装饰
- 禁止过于花哨的动效
- 禁止模糊的数据展示
```

## 适用场景
- 数据汇报
- KPI展示
- 业务分析
- 运营周报
- 数据驾驶舱
