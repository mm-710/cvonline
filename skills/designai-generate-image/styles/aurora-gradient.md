# 极光渐变风格 (Aurora Gradient)

## 风格ID
aurora-gradient

## 风格描述
极光渐变风格，使用流动的多彩渐变创造梦幻、神秘的视觉效果。适用于创意展示、品牌宣传、艺术类演示。

## 视觉特点
- 深色背景配合极光渐变
- 流动的多彩渐变效果
- 柔和的光晕和粒子
- 梦幻、神秘、高级感
- 动态流动的视觉感受

## 配色方案
- 背景：#0f0f1e 或 #1a1a2e
- 极光渐变：#00d9ff → #00ff88 → #ff00ff → #ff6b6b
- 主文字：#ffffff
- 辅助文字：#b0b0c0
- 光晕：低透明度渐变色

## 基础提示词

```
生成一张极光渐变风格的16:9图片。

视觉风格：
- 深色背景(#0f0f1e)
- 顶部或侧面有流动的极光渐变效果
- 极光颜色：青色→绿色→粉色→橙色
- 梦幻、神秘、高级感
- 类似北极光的视觉效果

配色：
- 极光渐变：#00d9ff → #00ff88 → #ff00ff → #ff6b6b
- 文字：白色
- 光晕使用低透明度渐变

元素风格：
- 内容区域使用深色半透明卡片
- 文字在极光背景上清晰可读
- 可以有微小的粒子或星点装饰
- 整体有流动感和动态感

禁止元素：
- 禁止纯色不变的背景
- 禁止过于密集的内容
- 禁止锐利的边缘
- 禁止与极光不协调的颜色
```
