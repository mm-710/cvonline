# 3D等距风格 (Isometric 3D)

## 风格ID
isometric-3d

## 风格描述
等距3D插画风格，使用等距视角展示立体图形。适用于技术架构、流程说明、产品展示。

## 视觉特点
- 等距投影视角（30°角）
- 立体的几何图形
- 明亮的色彩
- 清晰的层次结构
- 技术感和现代感

## 配色方案
- 背景：#f8f9fa 或 #ffffff
- 主色调：#4f46e5（紫蓝色）
- 辅助色：#06b6d4（青色）、#22c55e（绿色）
- 3D面颜色：使用同一色相的不同明度
- 顶面：亮色
- 侧面：中间色
- 底面/阴影：深色

## 基础提示词

```
生成一张等距3D风格的16:9图片。

视觉风格：
- 等距投影视角（30°角）
- 立体的几何图形和方块
- 明亮、现代的配色
- 类似等距插画的视觉效果
- 技术感和现代感

配色：
- 使用紫蓝色(#4f46e5)、青色(#06b6d4)、绿色(#22c55e)
- 3D物体的不同面使用同色系不同明度
- 背景使用浅色或白色

元素风格：
- 使用等距方块、柱体、平面
- 物体之间有清晰的层次关系
- 可以用线条连接不同的组件
- 图标和文字保持清晰可读

布局：
- 中心放置主要的3D场景
- 周围可以有标注和说明
- 整体构图平衡

禁止元素：
- 禁止透视畸变（必须保持等距）
- 禁止过于复杂的3D模型
- 禁止模糊的边缘
```

## 适用场景
- 技术架构图
- 系统组件图
- 流程说明
- 产品展示
- 概念图解
