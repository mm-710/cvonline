# 新拟物风格 (Neumorphism)

## 风格ID
neumorphism

## 风格描述
新拟物设计风格，通过柔和的阴影创造凸起或凹陷的效果。适用于UI展示、产品介绍、现代简约的演示。

## 视觉特点
- 浅色背景（通常是浅灰或米白）
- 柔和的凸起/凹陷效果
- 双阴影（亮边+暗边）
- 极简的图标和文字
- 柔和、舒适、现代感

## 配色方案
- 背景：#e0e5ec 或 #f0f0f3
- 主文字：#2d3436
- 辅助文字：#636e72
- 亮阴影：#ffffff
- 暗阴影：#a3b1c6
- 强调色：#0984e3（蓝色）或 #6c5ce7（紫色）

## 基础提示词

```
生成一张新拟物风格的16:9图片。

视觉风格：
- 浅灰色背景(#e0e5ec)
- 元素使用新拟物效果（凸起感，双阴影）
- 左上角亮阴影，右下角暗阴影
- 整体柔和、舒适、现代

配色：
- 背景：浅灰(#e0e5ec)
- 阴影：白色(#ffffff)和深灰(#a3b1c6)
- 强调色：蓝色(#0984e3)用于图标和按钮
- 文字：深灰色

元素风格：
- 圆角20-30px
- 凸起效果：左上亮阴影+右下暗阴影
- 凹陷效果：内阴影
- 图标使用单色线性风格
- 按钮有明显的凸起感

禁止元素：
- 禁止深色背景
- 禁止强烈的对比色
- 禁止尖锐的阴影
- 禁止复杂的渐变
```
