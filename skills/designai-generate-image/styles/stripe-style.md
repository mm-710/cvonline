# Stripe 风格 (Stripe Style)

## 风格ID
stripe-style

## 风格描述
Stripe 官网和文档的视觉风格，优雅的渐变背景、专业的配色、清晰的信息层级。适合技术博客、API文档、金融科技类展示。

## 视觉特点
- 深色渐变背景（深蓝紫到深蓝）
- 鲜明但和谐的渐变色彩
- 圆润的卡片和元素
- 专业且友好的视觉感受
- 清晰的信息架构

## 配色方案
- 背景：#0a2540（深蓝）渐变到 #1a1f71（深紫蓝）
- 主文字：#ffffff
- 辅助文字：#adbdcc
- 卡片背景：#0d3d5e 或半透明
- 主强调色：#635bff（紫色）、#00d4ff（青色）
- 渐变色：从 #635bff 到 #00d4ff
- 成功色：#24b47e
- 警告色：#ed5f74

## 基础提示词

```
生成一张Stripe风格的16:9技术架构图。

视觉风格：
- 深蓝色渐变背景，从深蓝(#0a2540)到深紫蓝(#1a1f71)
- 白色主文字，浅蓝灰色辅助文字
- 卡片使用深蓝色背景或半透明效果
- 圆润的元素风格，圆角16px
- 整体有金融科技的专业感

配色：
- 主渐变：紫色(#635bff)到青色(#00d4ff)
- 成功色：绿色(#24b47e)
- 图表和数据可视化使用渐变色填充
- 按钮和强调元素使用渐变

元素风格：
- 卡片有柔和的阴影和边框
- 数字和数据使用大字号突出显示
- 图标简约现代
- 网格布局整齐有序

禁止元素：
- 禁止过于复杂的装饰
- 禁止3D物体
- 禁止不和谐的配色
- 禁止过于密集的信息
```

## 适用场景
- 技术博客配图
- API文档图解
- 金融科技展示
- 数据可视化
