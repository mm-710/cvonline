# 渐变科技风格 (Gradient Tech)

## 风格ID
gradient-tech

## 风格描述
现代科技产品常用的渐变风格，深色背景配合霓虹渐变、发光效果，具有强烈的未来感和科技感。适合创新项目展示、科技大会、AI相关主题。

## 视觉特点
- 深色背景配合彩色渐变
- 霓虹灯般的发光效果
- 玻璃拟态(Glassmorphism)元素
- 流动的渐变色彩
- 强烈的视觉冲击力

## 配色方案
- 背景：#0f0f23（深蓝黑）到 #1a0a2e（深紫黑）
- 主文字：#ffffff
- 辅助文字：#a0a0b8
- 渐变1：#00d9ff（青色）→ #7b2cbf（紫色）
- 渐变2：#ff6b6b（粉红）→ #feca57（橙黄）
- 渐变3：#00f5d4（青绿）→ #00bbf9（天蓝）
- 发光色：使用渐变色的低透明度版本

## 注意事项

1. **渐变要和谐**：使用相近色相的渐变，避免突兀的颜色跳跃
2. **发光要柔和**：发光效果应该是柔和的，不是刺眼的纯白光
3. **层次要清晰**：虽然有很多效果，但信息层级要清晰
4. **不要过度装饰**：效果服务于内容，不能喧宾夺主
