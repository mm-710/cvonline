# AI/机器学习风格 (AI/ML Style)

## 风格ID
ai-ml-style

## 风格描述
AI和机器学习主题风格，使用神经网络、数据流、节点连接等元素。适用于AI项目展示、技术方案、研究报告。

## 视觉特点
- 深色科技感背景
- 神经网络节点和连接线
- 数据流动的视觉效果
- 渐变发光的节点
- 科技感、智能感、未来感

## 配色方案
- 背景：#0a0f1a 或 #0d1117
- 节点颜色：#00d4ff（青色）、#7b61ff（紫色）、#00ff88（绿色）
- 连接线：渐变色或半透明白色
- 发光效果：节点颜色的低透明度
- 主文字：#ffffff
- 辅助文字：#8b949e

## 基础提示词

```
生成一张AI/机器学习主题风格的16:9图片。

视觉风格：
- 深蓝黑色背景(#0a0f1a)
- 神经网络节点和连接线装饰
- 数据流动的视觉效果
- 节点带有发光效果
- 科技感、智能感、未来感

配色：
- 节点：青色(#00d4ff)、紫色(#7b61ff)、绿色(#00ff88)
- 连接线：渐变色或半透明
- 背景可以有微弱的网格
- 发光效果使用节点颜色

元素风格：
- 抽象的神经网络图案作为背景装饰
- 主要内容区域清晰可读
- 可以有数据点、节点、连接线
- 整体有智能和科技的感觉

内容区域：
- 使用深色半透明卡片
- 文字和数据清晰展示
- 图表使用渐变色

禁止元素：
- 禁止过于具象的机器人图像
- 禁止杂乱无章的连接线
- 禁止影响内容可读性的装饰
```

- 数据科学报告

- 智能系统架构
