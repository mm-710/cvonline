# Notion 风格 (Notion Style)

## 风格ID
notion-style

## 风格描述
Notion 产品的视觉风格，强调清晰的层级结构、柔和的视觉感受、优秀的可读性。适合知识分享和文档展示场景。

## 视觉特点
- 浅色/米白背景 (#ffffff 或 #fbfbfa)
- 深灰色文字，层级分明
- 柔和的圆角和阴影
- 清晰的网格布局
- 简约的图标和装饰

## 配色方案
- 背景：#ffffff 或 #fbfbfa
- 主文字：#37352f
- 辅助文字：#787774
- 边框：#e3e2e0
- 卡片背景：#f7f6f3
- 强调色：#2383e2（蓝色）、#0f7b6c（绿色）、#e03e3e（红色）
- 标签背景：#e3e2e0、#fadec9、#dbeddb、#d3e5ef

## 基础提示词

```
生成一张Notion风格的16:9技术架构图。

视觉风格：
- 浅色米白背景(#fbfbfa)
- 深灰色文字(#37352f)
- 柔和的圆角(8px)和轻微阴影
- 清晰的网格布局，留白充足
- 类似Notion产品的简约美感

配色：
- 使用柔和的色块标签区分不同类别
- 浅蓝(#d3e5ef)、浅绿(#dbeddb)、浅橙(#fadec9)、浅灰(#e3e2e0)
- 重点内容使用蓝色(#2383e2)文字

元素风格：
- 卡片使用浅灰背景(#f7f6f3)
- 表格使用细边框，表头加粗
- 标签使用圆角矩形，柔和底色

禁止元素：
- 禁止深色背景
- 禁止强烈的对比色
- 禁止复杂的装饰图案
- 禁止3D效果
```

## 适用场景
- 知识库文档
- 团队协作展示
- 项目规划图
- 流程说明图
