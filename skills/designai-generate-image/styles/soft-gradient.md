# 渐变柔和风格 (Soft Gradient)

## 风格ID
soft-gradient

## 风格描述
柔和渐变风格，使用柔和的粉彩色渐变，营造温暖、友好的视觉感受。适用于消费类产品、生活方式类内容、面向大众的演示。

## 视觉特点
- 柔和的粉彩色渐变背景
- 温暖、友好的色调
- 柔和的阴影和圆角
- 亲和力强
- 现代、清新、舒适

## 配色方案
- 渐变背景：
  - 粉蓝渐变：#a8edea → #fed6e3
  - 粉紫渐变：#fbc2eb → #a6c1ee
  - 橙粉渐变：#ffecd2 → #fcb69f
  - 蓝紫渐变：#a1c4fd → #c2e9fb
- 主文字：#2d3436 或 #ffffff
- 辅助文字：#636e72
- 卡片：白色或半透明白色

## 基础提示词

```
生成一张柔和渐变风格的16:9图片。

视觉风格：
- 柔和的粉彩色渐变背景
- 温暖、友好、亲和的视觉感受
- 柔和的阴影和大圆角
- 类似现代消费类App的设计语言
- 现代、清新、舒适

配色：
- 渐变背景：粉蓝(#a8edea → #fed6e3)或粉紫渐变
- 卡片：白色或半透明白色
- 文字：深灰色保证可读性
- 强调色：与渐变和谐的鲜明色

元素风格：
- 大圆角(16-24px)
- 柔和的阴影
- 可以有简约的线性图标
- 布局宽松，留白充足

禁止元素：
- 禁止深色背景
- 禁止锐利的边角
- 禁止强烈的对比色
- 禁止科技感过强的元素
```
