# 扁平设计风格 (Flat Design)

## 风格ID
flat-design

## 风格描述
扁平设计风格，去除所有3D效果和阴影，使用纯色块和简洁的图形。适用于信息图、流程图、教育类内容。

## 视觉特点
- 纯色背景，无渐变
- 扁平的色块和图形
- 无阴影、无3D效果
- 鲜明的对比色
- 简洁、清晰、现代

## 配色方案
- 背景：#ffffff 或饱和度低的浅色
- 主色块：使用 Material Design 或 Flat UI 配色
- 推荐色彩：
  - 蓝色：#3498db
  - 绿色：#2ecc71
  - 橙色：#e67e22
  - 红色：#e74c3c
  - 紫色：#9b59b6
  - 灰色：#95a5a6
- 主文字：#2c3e50
- 辅助文字：#7f8c8d

## 基础提示词

```
生成一张扁平设计风格的16:9图片。

视觉风格：
- 浅色或彩色纯色背景
- 扁平的色块和图形，无任何阴影
- 鲜明的对比色，清晰的视觉层次
- 类似 Google Material Design 或 Flat UI 的视觉语言
- 简洁、清晰、现代

配色：
- 使用饱和度适中的明亮色彩
- 蓝色(#3498db)、绿色(#2ecc71)、橙色(#e67e22)
- 每个区块使用不同的颜色区分
- 文字使用深色保证可读性

元素风格：
- 图形使用纯色填充
- 无阴影、无渐变、无3D效果
- 图标使用简单的几何形状
- 圆角适中(8-12px)
- 线条粗细统一

禁止元素：
- 禁止任何阴影效果
- 禁止渐变填充
- 禁止3D效果
- 禁止复杂的纹理
```

## 适用场景
- 信息图
- 流程图
- 教育类内容
- 说明文档
- 简洁的数据展示
