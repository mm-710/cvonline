# 企业商务风格 (Corporate Business)

## 风格ID
corporate-business

## 风格描述
专业的企业商务风格，适用于正式的商业演示、年度报告、投资人会议。强调专业性、可信度和清晰的信息传达。

## 视觉特点
- 白色或浅灰背景，干净专业
- 深蓝色为主色调，传达专业可信
- 清晰的网格布局
- 简洁的图表和数据可视化
- 适度的企业品牌色点缀

## 配色方案
- 背景：#ffffff 或 #f5f5f7
- 主文字：#1d1d1f
- 辅助文字：#6e6e73
- 主色调：#0066cc（企业蓝）
- 辅助色：#00a651（成功绿）、#ff9500（警示橙）
- 边框：#d2d2d7
- 卡片背景：#ffffff 带轻微阴影

## 基础提示词

```
生成一张企业商务风格的16:9 PPT图片。

视觉风格：
- 白色或浅灰背景，干净专业
- 深蓝色(#0066cc)作为主色调
- 清晰的网格布局，信息层次分明
- 适合正式商务场合的专业感

配色：
- 主色：企业蓝(#0066cc)
- 成功指标使用绿色(#00a651)
- 重点数据使用大字号突出

元素风格：
- 卡片使用白色背景+轻微阴影
- 图表简洁清晰
- 标题使用粗体，正文使用常规字重
- 适度的圆角(8px)

禁止元素：
- 禁止花哨的装饰
- 禁止渐变背景
- 禁止3D效果
- 禁止过于鲜艳的颜色
```

## 适用场景
- 商业演示
- 年度报告
- 投资人会议
- 公司内部汇报
- 正式的客户提案
