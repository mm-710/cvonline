# Linear 风格 (Linear Style)

## 风格ID
linear-style

## 风格描述
Linear 产品的视觉风格，深紫色调、微妙的渐变和发光效果、现代科技感。适合产品展示和SaaS类演示。

## 视觉特点
- 深紫/深蓝黑背景
- 紫色到蓝色的微妙渐变
- 柔和的发光效果
- 半透明毛玻璃卡片
- 流畅的圆角和阴影

## 配色方案
- 背景：#0d0d12 到 #1a1a2e 的渐变
- 主文字：#ffffff
- 辅助文字：#8a8aa3
- 卡片背景：rgba(255,255,255,0.05) 带模糊效果
- 边框：rgba(255,255,255,0.1)
- 主强调色：#5e6ad2（紫色）
- 辅助强调色：#26b5ce（青色）、#e5484d（红色）

## 基础提示词

```
生成一张Linear风格的16:9技术架构图。

视觉风格：
- 深紫黑色背景，带有细微的紫色到蓝色渐变
- 白色主文字，紫灰色辅助文字
- 卡片使用半透明毛玻璃效果，带有微妙的边框发光
- 整体有现代科技产品的精致感
- 类似Linear产品的视觉语言

配色：
- 主色调：紫色(#5e6ad2)
- 辅助色：青色(#26b5ce)
- 背景渐变：从深紫(#0d0d12)到深蓝(#1a1a2e)
- 卡片：半透明白色，带模糊效果

元素风格：
- 卡片圆角12px，带有柔和的发光边框
- 按钮和标签使用渐变填充
- 重点元素有微妙的光晕效果
- 整体布局留白充足

禁止元素：
- 禁止过于明亮的颜色
- 禁止强烈刺眼的发光
- 禁止3D物体装饰
- 禁止复杂的插画
```

## 适用场景
- SaaS产品展示
- 产品路线图
- 功能特性介绍
- 现代科技公司的演示
