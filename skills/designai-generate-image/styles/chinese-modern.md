# 中国风现代风格 (Chinese Modern)

## 风格ID
chinese-modern

## 风格描述
现代中国风设计，融合传统中国元素与现代设计语言。适用于中国市场的品牌展示、传统与现代结合的项目。

## 视觉特点
- 中国传统色彩（红、金、墨、白）
- 现代简约的布局
- 传统纹样的现代化运用
- 留白与意境
- 东方美学与现代设计结合

## 配色方案
- 背景：#faf8f5（米白）或 #1a1a1a（墨黑）
- 主色：#c41e3a（中国红）或 #d4af37（金色）
- 辅助色：#2c5545（松绿）、#8b4513（檀木棕）
- 文字：#2c2c2c 或 #f5f5f5
- 线条：#d4af37（金线）

## 基础提示词

```
生成一张现代中国风风格的16:9图片。

视觉风格：
- 米白或墨黑背景
- 中国传统色彩（红、金、墨绿）
- 大量留白，意境深远
- 传统元素现代化（如简化的祥云、山水轮廓）
- 东方美学与现代设计结合

配色：
- 主色：中国红(#c41e3a)或金色(#d4af37)
- 辅助色：松绿(#2c5545)
- 背景：米白(#faf8f5)或墨黑(#1a1a1a)
- 点缀：金色线条或图案

元素风格：
- 可以有简化的传统纹样（祥云、山水、窗格）
- 文字使用中文字体，排版讲究
- 金色边框或分隔线
- 整体构图遵循东方美学

禁止元素：
- 禁止西方风格的装饰
- 禁止过于复杂的传统图案
- 禁止不协调的色彩
- 禁止过于拥挤的布局
```

## 适用场景
- 中国市场品牌展示
- 传统文化项目
- 节日主题（春节、中秋等）
- 高端品牌演示
- 文化类内容
