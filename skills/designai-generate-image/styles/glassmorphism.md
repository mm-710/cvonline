# 玻璃拟态风格 (Glassmorphism)

## 风格ID
glassmorphism

## 风格描述
玻璃拟态设计风格，2020年后流行的现代UI设计趋势。适用于现代产品展示、创意项目、科技类演示。

## 视觉特点
- 模糊透明的玻璃效果
- 柔和的渐变背景
- 半透明卡片带模糊效果
- 微妙的边框和阴影
- 现代、通透、高级感

## 配色方案
- 背景渐变：#667eea → #764ba2（蓝紫渐变）
- 或背景渐变：#f093fb → #f5576c（粉红渐变）
- 玻璃卡片：rgba(255,255,255,0.15)
- 边框：rgba(255,255,255,0.3)
- 主文字：#ffffff
- 辅助文字：rgba(255,255,255,0.7)

## 基础提示词

```
生成一张玻璃拟态风格的16:9图片。

视觉风格：
- 柔和的渐变背景（蓝紫或粉红渐变）
- 卡片使用玻璃拟态效果（半透明+背景模糊+白色边框）
- 整体通透、现代、高级感
- 类似 iOS、Windows 11 的毛玻璃设计语言

配色：
- 背景：蓝紫渐变(#667eea → #764ba2)
- 玻璃卡片：半透明白色，背景模糊
- 边框：白色半透明，带发光效果
- 文字：白色

元素风格：
- 卡片圆角16-24px
- 边框1px白色半透明
- 内部有轻微的白色内发光
- 阴影柔和
- 图标使用线性风格

禁止元素：
- 禁止纯色不透明卡片
- 禁止锐利的边角
- 禁止强烈的黑色元素
- 禁止过于复杂的装饰
```
