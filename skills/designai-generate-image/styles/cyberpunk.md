# 赛博朋克风格 (Cyberpunk)

## 风格ID
cyberpunk

## 风格描述
赛博朋克视觉风格，霓虹灯、暗色调、科幻感。适用于游戏、科幻、前沿科技类项目展示。

## 视觉特点
- 深色背景（黑色或深紫）
- 霓虹灯效果（粉色、青色）
- 故障艺术（Glitch）元素
- 网格和线条装饰
- 未来感、科幻感、叛逆感

## 配色方案
- 背景：#0a0a0f 或 #1a0a2e
- 主霓虹色：#ff00ff（品红）、#00ffff（青色）
- 辅助霓虹色：#ff6b6b（粉红）、#ffd93d（黄色）
- 主文字：#ffffff
- 发光效果：霓虹色低透明度外发光

## 基础提示词

```
生成一张赛博朋克风格的16:9图片。

视觉风格：
- 深黑色背景(#0a0a0f)
- 霓虹灯效果（粉色、青色为主）
- 可以有故障艺术（Glitch）效果
- 网格线或扫描线装饰
- 强烈的未来感和科幻感

配色：
- 主霓虹色：品红(#ff00ff)和青色(#00ffff)
- 元素带有发光效果
- 可以有色彩分离效果
- 背景可以有暗色网格

元素风格：
- 文字带霓虹发光效果
- 可以有扫描线或噪点
- 边框使用霓虹色
- 图形有轻微的故障效果
- 整体有数字感和科技感

禁止元素：
- 禁止明亮的背景
- 禁止柔和的粉彩色
- 禁止圆润可爱的风格
- 禁止传统的商务风格
```
