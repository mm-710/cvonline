# 科技发布会风格 (Tech Launch)

## 风格ID
tech-launch

## 风格描述
科技产品发布会风格，灵感来源于 Apple、Google I/O、Microsoft Build 等科技大会。适用于产品发布、技术发布会、重大公告。

## 视觉特点
- 深色背景（黑色或深灰）
- 大胆的渐变色彩
- 超大标题，震撼视觉
- 产品/功能居中展示
- 简洁有力的信息传达

## 配色方案
- 背景：#000000 或 #1a1a1a
- 主文字：#ffffff
- 渐变色：多彩渐变（蓝→紫→粉）
- 强调色：品牌色或彩虹渐变
- 辅助文字：#a1a1a6

## 基础提示词

```
生成一张科技发布会风格的16:9 PPT图片。

视觉风格：
- 纯黑背景(#000000)
- 超大标题，震撼视觉效果
- 使用彩色渐变突出重点（蓝色→紫色→粉色）
- 产品或功能居中展示
- 类似Apple/Google发布会的视觉语言

配色：
- 背景：纯黑
- 标题：白色或渐变色
- 数字和关键词使用彩虹渐变效果
- 辅助信息使用灰色

元素风格：
- 标题超大（72pt以上效果）
- 信息极简，每屏只有1-2个核心信息
- 大量留白
- 可以有微妙的光效装饰

禁止元素：
- 禁止过多文字
- 禁止复杂的表格
- 禁止拥挤的布局
```

## 适用场景
- 产品发布会
- 技术发布会
- 重大功能公告
- 品牌宣传
- CEO演讲
