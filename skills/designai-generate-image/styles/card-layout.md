# 卡片式布局风格 (Card Layout)

## 风格ID
card-layout

## 风格描述
现代卡片式布局风格，使用Bento Grid布局展示多个信息块。适用于功能介绍、产品特性、多维度展示。

## 视觉特点
- Bento Grid 不规则网格布局
- 圆角卡片组合
- 每个卡片展示一个要点
- 清晰的视觉层次
- 现代、灵活、信息丰富

## 配色方案
- 背景：#f5f5f7 或 #1c1c1e（浅色/深色模式）
- 卡片背景：#ffffff 或 #2c2c2e
- 主文字：#1d1d1f 或 #ffffff
- 强调色：根据内容选择品牌色
- 边框：透明或浅灰

## 基础提示词（浅色模式）

```
生成一张卡片式布局风格的16:9图片。

视觉风格：
- 浅灰色背景(#f5f5f7)
- Bento Grid 不规则网格布局
- 白色圆角卡片，带轻微阴影
- 类似 Apple 官网的 Bento 布局
- 现代、灵活、信息丰富

配色：
- 背景：浅灰(#f5f5f7)
- 卡片：白色(#ffffff)
- 文字：深灰(#1d1d1f)
- 强调色：品牌蓝或其他强调色

元素风格：
- 卡片圆角20px
- 卡片大小不一，形成不规则网格
- 大卡片放主要信息，小卡片放次要信息
- 每个卡片有图标、标题、简短描述
- 卡片之间间距适中(16-24px)

禁止元素：
- 禁止规则的等大网格
- 禁止没有圆角的卡片
- 禁止过于密集的布局
```

## 基础提示词（深色模式）

```
生成一张卡片式布局风格的16:9图片（深色模式）。

视觉风格：
- 深黑色背景(#1c1c1e)
- Bento Grid 不规则网格布局
- 深灰色圆角卡片(#2c2c2e)
- 类似 Apple 官网的 Bento 布局（深色版）
- 现代、灵活、信息丰富

配色：
- 背景：深黑(#1c1c1e)
- 卡片：深灰(#2c2c2e)
- 文字：白色(#ffffff)
- 强调色：亮色系（蓝、绿、橙）
```

## 适用场景
- 功能介绍
- 产品特性展示
- 多维度信息展示
- 服务介绍
- 技术能力展示
