# Apple Keynote 风格 (Apple Keynote Style)

## 风格ID
apple-keynote

## 风格描述
Apple 发布会和 Keynote 演示的视觉风格，极简留白、大标题、高端质感。适合重要演讲、产品发布、高层汇报。

## 视觉特点
- 纯黑或纯白背景
- 超大标题，极简文字
- 大量留白
- 精致的细节
- 聚焦核心信息

## 配色方案

### 深色模式
- 背景：#000000（纯黑）
- 主文字：#ffffff
- 辅助文字：#86868b
- 强调色：#0071e3（Apple蓝）
- 渐变：彩虹渐变或蓝紫渐变

### 浅色模式
- 背景：#ffffff（纯白）
- 主文字：#1d1d1f
- 辅助文字：#86868b
- 强调色：#0071e3（Apple蓝）

## 基础提示词

```
生成一张Apple Keynote风格的16:9技术架构图。

视觉风格：
- 纯黑背景(#000000)
- 超大白色标题，SF Pro字体风格
- 极简布局，大量留白
- 信息高度精简，每个区域只保留核心内容
- 类似Apple发布会的高端质感

配色：
- 主色：白色文字
- 强调色：Apple蓝(#0071e3)
- 可使用彩虹渐变突出重要元素
- 辅助信息使用灰色(#86868b)

元素风格：
- 标题超大（48-72pt效果）
- 正文精简，使用要点列表
- 卡片使用深灰色(#1c1c1e)背景
- 圆角统一使用20px
- 阴影极其柔和

设计原则：
- Less is more
- 每个区域只传达一个核心信息
- 用留白引导视觉焦点
- 用大小对比强调层级

禁止元素：
- 禁止任何复杂的装饰
- 禁止过多的文字
- 禁止拥挤的布局
- 禁止不必要的边框线
- 禁止3D效果
```

## 适用场景
- 高层汇报
- 产品发布
- 年度总结
- 战略演讲

## 注意事项

1. **内容极简化**：将复杂信息提炼为核心要点
2. **层级清晰**：使用字号大小区分信息层级
3. **留白充足**：至少40%的画面是留白
4. **聚焦重点**：每个区域只有1-2个核心信息
