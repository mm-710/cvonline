# 参数详解与展示逻辑

## 参数说明

### garden_name（必填）

园区名称或简称，脚本会做模糊匹配，以下别名均可识别：

| 用户输入 | 实际匹配 |
|----------|----------|
| `元中心` | 北京·元中心 |
| `北京元中心` | 北京·元中心 |
| `万家灯火` | 北京·万家灯火大厦 |
| `万家灯火大厦` | 北京·万家灯火大厦 |
| `百度国际` | 深圳·百度国际大厦 |
| `欧美金融` | 杭州·欧美金融中心 |
| `星耀` | 杭州·星耀中心 |

**缺失时处理：** 不调用脚本，先追问用户园区，推荐追问话术：
> 请告诉我你在哪个园区（例如：元中心 / 万家灯火 / 欧美金融中心）。

---

### area_name（可选）

档口/区域筛选关键词，例如：`西部马华`、`轻食`。

- 传入后仅查询匹配档口（按档口名/区域名做模糊匹配）
- 不传则查询园区全部档口

---

### meal_type（可选）

显式指定餐型：

- `1` = 早餐
- `2` = 午餐
- `3` = 晚餐
- `4` = 夜宵

不传时：
1) 先从 `taste_preference` 文本中提取餐次（如“中午吃什么”）
2) 若仍未命中，再按系统时间自动推断（10点前=早餐，10-14点=午餐，14点后=晚餐）

---

### taste_preference（可选）

口味偏好关键词，支持以下场景：

| 示例输入 | 匹配逻辑 |
|----------|----------|
| `辣` / `麻辣` / `重口味` | 扩展为：辣、麻、麻辣、香辣、椒、孜然 |
| `清淡` / `低热量` / `减脂` / `轻食` | 扩展为：清淡、少油、低脂、轻食、蒸、水煮、凉拌、沙拉、鸡胸、鱼、虾 |
| `素` / `素食` / `不吃肉` | 扩展为：素、豆腐、菌、青菜、蔬菜、沙拉 |
| `不要葱` / `不吃辣` | 识别为负向过滤，从结果中排除含“葱”/“辣”的菜 |
| 直接写具体食材/菜名 | 在菜名和描述中做包含匹配 |

**泛化请求处理（不做口味过滤）：**
- `今天有什么吃的` / `吃什么` / `随便` / `推荐` 等泛化语义，直接返回全量菜单

---

### custom_date（可选）

格式 `YYYY-MM-DD`，不填则默认今天。

---

### max_results（可选）

最多返回多少条菜品（去重后），默认 50，范围 1-200。

若用户明确点名某个档口（如“西部马华有什么”）且未手动设定上限，系统可自动放宽上限以减少截断。

---

### per_store_max_dishes（可选）

每个档口在文本输出中最多展示多少道菜，仅影响展示截断，不影响实际抓取数量。默认 50。

---

## 展示逻辑

### 全量查询（无具体口味）

当用户没有具体口味关键词时（如“今天有什么吃的”），结果按**美食广场品类**分组展示：

| 品类 | 识别关键词 |
|------|-----------|
| 健康轻食 | 轻食、沙拉、鸡胸、低脂、减脂、超级碗、能量碗 |
| 粉面水饺 | 粉、面、米线、刀削、拉面、拌面、水饺、馄饨、锅贴 |
| 小吃炸串 | 炸串、串、烤肠、鸡块、薯、卷饼、夹馍、小吃 |
| 汤粥与简餐 | 汤、粥、茶碗蒸、蒸蛋、瓦罐 |
| 饮品甜点 | 饮、奶茶、冰粉、甜、曲奇、可乐、茶、果汁、糍粑 |
| 特色风味 | 麻辣、藤椒、湘、川、粤、港、日式、叻沙、风味、烧腊 |
| 中式快餐/正餐 | 套餐、盖饭、拌饭、炒饭、快餐、正餐、零点、自选 |
| 其他 | 以上均不匹配 |

同时使用**跨档口轮询**选取菜品，避免结果集中在某一个档口。

### 口味 / 点名档口查询

按**区域 → 档口**分组展示，便于快速定位。

## 与 `cafeteria-takeout` 的职责隔离

本 Skill 只负责堂食菜单查询。以下需求必须转给 `cafeteria-takeout`：

- 外卖下单（如“帮我订午饭”）
- 查询外卖订单（如“我的外卖到哪了”）
- 取消外卖订单（如“帮我取消今天的外卖”）

当识别到上述意图时，应直接说明当前 Skill 不支持，并引导用户使用 `cafeteria-takeout`。

### 标准路由回复模板（建议固定使用）

```text
当前能力：我仅支持食堂堂食菜单查询（按园区/档口/餐型/口味）。
暂不支持：外卖下单、外卖查单、取消外卖订单。
建议操作：请使用 cafeteria-takeout Skill 处理外卖相关需求。
```
