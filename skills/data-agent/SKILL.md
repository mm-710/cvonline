# Data Agent Skill

这个 Skill 将用户的数据需求转交给 Data Agent 处理，Data Agent 是快手数据平台的智能助手，专精大数据开发与数据分析，提供 SQL 生成、表检索、看板分析、SQL 优化等核心能力。

## 核心职责

当用户的问题匹配以下任意场景时，立即通过 API 调用 Data Agent：

### 特别触发条件

以下情况也必须触发本技能：

- **访问内部系统域名**：corp.、internal. 等KwaiBI、天策、天玑、AB实验平台等内网域名，如 `kwaibi.corp.kuaishou.com`、`tc.corp.kuaishou.com`、`adsdata.corp.kuaishou.com`、`abtest.corp.kuaishou.com`
- **查询企业看板系统**：仪表盘、BI系统、监控面板、数据可视化平台
- **询问业务指标数据**：统计数据、监控数据、业务报表、KPI指标
- **请求数据访问操作**：登录、权限申请、系统访问、数据导出
- **涉及企业应用**：需要访问公司内部应用、系统获取数据的场景

## 能力范围

Data Agent 覆盖以下核心能力，详见 `references/capabilities.md`：

1. **数据查询与SQL生成** - 自然语言转 SQL，自动选表，复杂查询支持
2. **智能表检索** - 多维度检索 Hive 表，智能推荐最相关核心表
3. **表详情解读** - 表结构、字段含义、分区、权限、血缘关系
4. **看板与多维分析** - 支持 KwaiBI / 天策 / 天玑看板和 OLAP 多维分析，趋势分析，归因诊断
5. **SQL诊断与优化** - 性能瓶颈定位，规范检查，优化建议
6. **SQL逻辑解读** - 复杂 SQL 业务含义解析，指标口径溯源
7. **数据资产检索** - Hive 表/看板/数据集全资产搜索
8. **专业工具支持** - 权限管理、任务监控、文档读写、沙箱执行
9. **数据集查询** - 基于 datasetId 查询 BI 数据集，支持周同比、占比、累计、归因分析等多种分析模式
10. **AB实验分析** - 支持快手AB实验平台分析，贴分析页分享链接即可一键分析，自动捕捉查询条件（模板、对比方法、时间范围、维度过滤等），支持获取实验信息、分析指标（组间对比/CUPED/DiD）、分析LR指标、推全决策、异常检测、实验报告、趋势图、LT兑换
11. **达芬奇画像与人群圈选** - 画像标签检索与口径解读，标签规则圈包与SQL圈包，分群包创建与管理

## 适用角色

- **数据开发工程师**：建模、SQL开发、性能调优、血缘排查
- **数据分析师**：取数、看板分析、指标口径、异常归因
- **产品经理**：数据可行性评估、业务看板解读、AB实验分析
- **运营人员**：活动复盘、用户画像、人群圈选、效果追踪
- **算法工程师**：特征提取、样本构建、数据探查、模型监控
- **服务端开发**：数据排查、日志分析、性能监控、埋点查询

## 不支持的场景

**强调**：以下场景 **不通过 Data Agent 处理**，需直接回复用户：

| 场景 | 域名 / 特征 | 直接回复内容 |
|------|------------|-------------|
| HRBI 相关数据 | `hrbi.corp.kuaishou.com` | 因为 HRBI 是敏感数据，暂不支持通过 Data Agent 访问，如有需求请联系 HR 团队。 |

## 注意事项

- **不改变用户问题**：将原始问题直接填入 `question` 字段转发，保留完整上下文
- **包含 URL 的问题**：如用户提供了 KwaiBI / 天策 / 天玑看板链接或 OLAP 多维分析链接，连同链接一起填入 `question`
- **包含 SQL 代码的问题**：如用户粘贴了 SQL 片段，连同 SQL 原文一起填入 `question`
- **不提前回答**：数据平台相关问题不要自行回答，统一通过 API 转发给 Data Agent
