# Data Agent 详细能力说明

## 一、数据查询与 SQL 生成

用自然语言描述数据需求，Data Agent 自动转化为可执行 SQL。

**能力要点**：
- 自动找到最合适的 Hive 表
- 准确匹配字段和口径
- 生成规范、高效的 SQL
- 支持复杂查询、多表关联

**示例提问**：
- "查询最近7天各直播间的活跃用户数"
- "统计上个月不同商品类目的GMV和订单量"
- "获取昨天新增注册用户的画像特征"

---

## 二、智能表检索

不知道用什么表时，Data Agent 帮你精准定位。

**能力要点**：
- 支持按业务主题、字段名、表名等多维度检索
- 智能推荐最相关的核心表
- 展示表的热度、标签、负责人等关键信息
- 基于数据专题精准匹配

**示例提问**：
- "查用户画像相关的表有哪些？"
- "包含订单金额字段的表推荐几个"
- "电商直播间行为数据的表用哪个？"

---

## 三、表详情解读

深入了解某张表的所有信息。

**能力要点**：
- 表结构、字段含义、更新频率
- 分区情况、数据样例
- 权限查询与申请
- 数据血缘关系（上下游表）

**示例提问**：
- "详细介绍下 dws_user_profile_user_aggr_df 这张表"
- "我有哪些字段的查询权限？"
- "这张表的最新分区是什么时候？"

---

## 四、看板与多维分析（cortex_dashboard-analysis）

分析 KwaiBI、天策、天玑等平台的看板数据，解读多维分析（OLAP）链接的数据，支持趋势分析、异常诊断、对比分析、图表解读。

**能力要点**：
- 自动解析 KwaiBI、天策、天玑（adsdata）平台的看板数据
- 支持 OLAP 多维分析链接解读
- 趋势分析、异常诊断、对比分析
- 生成结构化分析报告
- MECE 归因、漏斗分析、贡献度分解等专业方法

**支持的平台与 URL 格式**：

| 平台 | URL 示例 | 识别方式 |
|------|---------|---------|
| KwaiBI 看板 | `https://kwaibi.corp.kuaishou.com/pc/dashboard/preview?dashboardId=xxx&sheetId=xxx&tabIds=xxx` | URL 包含 `dashboardId`，无 `insightConfigId` |
| 天玑（adsdata）看板 | `https://adsdata.corp.kuaishou.com/iframe?id=xxx` | 天玑 URL，提取 `menuId` |
| OLAP 多维分析 | `https://kwaibi.corp.kuaishou.com/olap?shareId=xxx` | URL 包含 `/olap?shareId=` |

**看板分析处理流程**（Data Agent 内部自动完成，调用方只需转发用户问题即可）：

1. **KwaiBI 看板**：Data Agent 自动识别 `dashboardId` → 定位 sheet → 获取所有图表数据 → 生成概览分析
2. **天玑（adsdata）看板**：Data Agent 自动识别天玑 URL → 提取看板 widget → 同 KwaiBI 流程分析
3. **OLAP 多维分析**：Data Agent 自动识别 `/olap?shareId=` → 提取数据字段和结果 → 生成概览分析

**示例提问**：
- "帮我看看这个看板 https://kwaibi.corp.kuaishou.com/pc/dashboard/preview?dashboardId=2093100&sheetId=321716&tabIds=1025467"
- "帮我看看这个天玑看板 https://adsdata.corp.kuaishou.com/iframe?id=10583"
- "分析一下这个多维分析 https://kwaibi.corp.kuaishou.com/olap?shareId=54594606"
- "为什么昨天的转化率突然跌了？"
- "对比下这两个渠道的用户留存"

## 九、数据集查询

基于 datasetId 查询 BI 数据集，支持多种分析模式。Data Agent 会自动校验字段存在性、生成专用 BI SQL 并执行查询。

**能力要点**：
- 按 datasetId 定位数据集，自动获取 schema 校验字段
- 支持周同比/环比变化率分析
- 支持维度占比分析（各维度值占总体比例）
- 支持按日累计（RUNNING_SUM）分析
- 支持归因分析（各维度对指标变化的贡献度）
- 字段不存在时智能提示

**支持的分析模式**：

| 分析模式 | 说明 | 使用的 BI SQL 函数 |
|---------|------|-------------------|
| 周同比/环比 | 对比指标在时间维度上的变化率 | `YEAR_ON_YEAR()` |
| 维度占比 | 各维度值占总体的比例 | `EXCLUDE` 语法 |
| 按日累计 | 指标随时间逐日累加 | `RUNNING_SUM()` |
| 归因分析 | 各维度对指标波动的贡献度 | 分维度对比计算 |
| 日期范围 | 灵活的日期过滤 | `CUSTOM_DATE_RANGE()` |

**处理流程**（Data Agent 内部自动完成，调用方只需转发用户问题即可）：
1. 解析用户问题中的 datasetId → 调用 `commonDatasetSchema` 获取数据集 schema
2. 校验用户提到的字段是否存在于数据集中
3. 若字段存在 → 生成对应的 BI SQL 并执行
4. 若字段不存在 → 返回提示信息，建议用户确认数据源

**示例提问**：
- "数据集12下昨日风控后支付GMV的周同比变化率"
- "数据集45下昨日各店铺类型的风控后支付GMV及占比"
- "数据集45下最近7天风控后支付GMV按日累计"
- "数据集9下按FT进行总消耗的归因分析"
- "数据集9中查询用户的LTV"（字段不存在时自动提示）

## 十、AB 实验分析

快手 AB 实验平台官方能力支持，一键分析实验效果，自动捕捉页面查询条件。

**能力要点**：
- 自动解析 abtest.corp.kuaishou.com 分析页分享链接
- 自动捕捉查询条件（模板、对比方法、时间范围、维度过滤等）
- 获取实验基本信息（实验名称、状态、版本、流量配置等）
- 分析核心指标：组间对比、CUPED 分析、DiD（双重差分）方法
- 分析 LR（长期留存）指标
- 推全决策建议（基于统计显著性和业务影响评估）
- 异常检测与数据质量校验
- 生成完整实验报告
- 趋势图分析（指标随时间变化）
- LT（长期）兑换分析

**示例提问**：
- "分析这个实验：https://abtest.corp.kuaishou.com/analysis/share?experimentId=xxx&templateId=yyy"
- "帮我看下实验【优化推荐算法V2】的核心指标表现"
- "这个实验的 CUPED 分析结果怎么样？"
- "给我生成实验xxx的推全决策建议"
- "分析下这个实验的长期留存指标"
- "检查实验数据有没有异常"
- "生成完整的实验分析报告"
- "看下实验指标的趋势图，有没有波动"

## 十一、达芬奇画像与人群圈选

通过达芬奇画像平台的标签体系，帮助用户检索标签、理解标签口径、圈选目标人群并创建分群包。

**能力要点**：

- **标签检索**：根据关键词搜索画像标签，查询标签下的枚举值与维度值，通过维度值反查所属标签
- **标签口径解读**：查看标签的定义、配置信息与描述方式，帮助用户理解标签含义与使用规范
- **标签规则圈包**：通过标签组合条件（交集/并集/差集）圈选用户人群，生成结构化的标签规则 DSL，支持预估人群量级
- **SQL 圈包**：通过 HiveSQL 圈选任意实体人群（用户/设备/主播/视频/商品等），适用于标签无法覆盖的复杂圈选场景
- **分群包创建与管理**：支持一次性和周期更新的分群包创建，自动校验参数合法性

**示例提问**：

- "有哪些活跃度相关的标签？"
- "这个标签的口径是什么？支持哪些维度值？"
- "帮我圈一批一线城市、18-30岁的女性用户"
- "用SQL圈选最近30天有过直播间消费的高价值用户"
- "预估下这个人群有多少人"
- "创建一个分群包，名字叫'高活跃年轻女性'"
