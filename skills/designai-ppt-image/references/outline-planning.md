# Step 1: 提取物料，规划 PPT 大纲

收到用户物料后，**首先深度分析内容**，提取出：
- 核心主题和目的（这是一个什么样的PPT？给谁看？）
- 关键章节结构（逻辑脉络）
- 每页的核心内容：标题、核心观点、关键数据、结论

## 输出大纲格式

让用户确认后再继续：

```
📋 基于你的物料，规划以下 PPT 大纲（共 N 张）：

1. [封面] {标题} — {副标题}
2. [目录] 全文结构概览
3. [内容] {章节标题} — 核心观点：{1-2句话}；关键数据：{数据}
4. [数据] {数据页标题} — 展示数据：{具体数字/对比}
5. [结论] {结论标题} — {行动建议}

内容来源：已从你的物料中提取，如有遗漏或需要调整，请告诉我。
```

## 针对不同输入类型的处理方式

| 输入类型 | 处理方式 |
|---------|---------|
| 话题/关键词 | 基于话题规划结构，根据已有知识补充合理内容 |
| 文档文本/长文 | 提取章节结构、核心论点、关键数据，按逻辑重组为PPT大纲 |
| `.pptx/.pdf/.key` | 解析原有结构，按页提取标题+内容，可选「优化重排」或「保持原结构」 |
| URL | 抓取页面内容，提取核心信息规划大纲 |
| 数据表格 | 识别数据维度，规划数据可视化型幻灯片 |

## 确认时机

- **话题/模糊描述时**：等用户确认大纲
- **完整文档/URL 时**：提取后直接展示，3秒无异议自动继续
