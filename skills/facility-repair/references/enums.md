## 一、园区 / 楼栋 / 楼层 / 房间（parkId / buildId / floorId / roomId）

### 获取方式

```bash
uv run scripts/repair_api.py --action get_enums
```

### 数据结构示例

```
园区 [parkId] 园区名称
  楼栋 [buildId] 楼栋名称
    楼层 [floorId] 楼层名称  → roomId:房间名称、roomId:房间名称...
```

### 高频园区示例（仅供参考）

#### 北京·元中心（parkId: 58）

**1号楼（buildId: 75，常见表述：T1）**

**2号楼（buildId: 76，常见表述：T2）**

## 三、工单状态枚举（state）

| state 值 | 中文含义 | 对应 query.type |
|----------|---------|----------------|
| `PROCESSING` | 进行中 | type=1 |
| `FINISH` | 已完成待评价 | type=2 |
| `FOLLOWUP` | 已评价（完成） | type=3 |
| `CANCEL` | 已取消 | - |

---

## 四、评分字段说明

**attitude（服务态度）/ speed（服务速度）/ quality（服务质量）**

| 值 | 含义 |
|----|------|
| 1 | ⭐ 非常差 |
| 2 | ⭐⭐ 较差 |
| 3 | ⭐⭐⭐ 一般 |
| 4 | ⭐⭐⭐⭐ 较好 |
| 5 | ⭐⭐⭐⭐⭐ 非常好 |

> 当任意维度评分 ≤2 时，`description` 字段**必填**。
