## 万家灯火楼层命名规则

### 格式说明

万家灯火的楼层命名格式：**`数字 + F + 字母 + 区`**

示例：
- `1FA区` = 1层 A区
- `5FB区` = 5层 B区
- `8FB区` = 8层 B区
- `7FC区` = 7层 C区

### 步骤1：解析用户表述

| 输入格式 | 提取规则 | 示例 |
|---------|---------|------|
| `B区8层` | 字母 + 数字 | B + 8 |
| `8B` | 数字 + 字母 | 8 + B |
| `8FB区` | 已是标准格式 | 8FB |

- `B + 8` → `8FB区`
- `5 + B` → `5FB区`
