# 快手报修系统测试场景

## 测试场景 1：万家灯火特殊楼层格式

**用户输入**：
```
位置：万家灯火 B区8层
问题：空调温度太热
手机：13800010001
```

**关键识别点**：
- 万家灯火楼层格式：`数字 + F + A/B/C + 区`
- `B区8层` = `8FB区` ← 不是 `5FB区`！

**正确识别**：
- 园区：北京·万家灯火 (parkId: 56)
- 楼栋：万家灯火大厦 (buildId: 73)
- 楼层：8FB区 (floorId: 315) ← **不是 310！**
- 类型：暖通 (typeId: 101)

**脚本参数**：
```bash
uv run scripts/repair_api.py --action submit \
  --phone 13800010001 \
  --parkId 56 \
  --buildId 73 \
  --floorId 315 \
  --typeId 101 \
  --description "空调温度太热"
```

**常见错误**：
- ❌ `B区8层` 误识别为 `5FB区` (floorId: 310)
- ❌ 只看到 B 和数字，匹配成了 5FB
- ✅ 正确：B区8层 = 8FB区 (floorId: 315)
