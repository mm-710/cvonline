# 快手理发店 - 用户操作旅程

## 审查目标

- 确认脚本覆盖了用户旅程中的所有关键操作节点（查看、预约、取消）。
- 确认写操作（预约/取消）有明确的用户确认步骤，不会自动静默提交。
- 确认脚本对"今日已约满"等业务状态有正确的提示，而不是静默返回空。

## 常见违规与推荐修复

### 脚本未覆盖职场切换旅程

- 违反规范：用户期望能在不同职场（北京元中心/万家灯火）之间切换查询。
- 推荐修复：`--list` 和 `--date` 命令均应支持 `--shop` 参数，并通过 `--list-shops` 枚举可用职场。
- 自动修复：不支持。

### 写操作无确认机制

- 违反规范：`--book` 应有二次确认机制，防止 AI agent 误触发预约。
- 推荐修复：`--book` 命令必须配合 `--confirm` 参数才能实际提交，不加时只打印预约信息。
- 自动修复：不支持。

### 理发师列表为空时无明确提示

- 违反规范：今日已约满时，接口可能返回空数组，若脚本不提示原因，AI agent 会误判为系统故障。
- 推荐修复：当列表为空时，输出"今日可能已约满，可使用 --date 查询未来日期"等引导信息。
- 自动修复：不支持。

## 用户操作旅程

### 读操作旅程
1. 查看所有理发师的当日预约情况（状态、今日可约/已约满）
2. 查看某理发师的简介、价目表、可预约时间段
3. 查看我的历史预约记录
4. 查询特定日期（如3-25）哪些理发师还有空余时间段

### 写操作旅程
5. **预约某理发师的某一时间段**（选择服务→选择日期→选择时间段→填手机号→确认预约）
6. **取消已有预约**（进入"我的预约"→取消）
