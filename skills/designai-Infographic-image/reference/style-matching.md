## 风格引导句详细描述（用于路线B提示词）

> 以下引导句直接对应 SKILL.md 映射表，按编号排列。
> 路线B提示词在正文前加一行「视觉风格：{引导句}」即可。

### 编号 1 — 系统自动匹配
根据内容领域×基调从风格矩阵自动选择最适合的风格引导句（详见上方「按场景选风格」）。

### 编号 2 — 手绘漫画风
```
奶油白底搭配均匀黑色线稿，色块平涂，有趣味性的手绘人物和场景感，亲切温暖的科普漫画氛围。
```

### 编号 3 — 日漫动感风
```
明亮鲜艳的动漫插图风格，活力色彩搭配对话气泡和Q版人物，充满动感和青春活力。
```

### 编号 4 — 教科书插画风
```
浅蓝白底搭配写实精细插图和标注线条，教科书质感，清晰的图解说明风格。
```

### 编号 5 — 萌系卡通风
```
糖果色系搭配Q版圆润人物和可爱图标，柔和渐变背景，温馨轻松的卡通氛围。
```

### 编号 6 — 专业数据图表风
```
白底蓝灰色系搭配专业图表和网格对齐，严谨清晰的商务数据可视化风格。
```

### 编号 7 — 企业简报风
```
浅灰白底搭配细线分割和规整排版，专业企业内部文档质感，沉稳低调。
```

### 编号 8 — 新闻杂志风
```
大字标题搭配分栏排版，黑白灰为主调偶有彩色点缀，报纸杂志的新闻质感。
```

### 编号 9 — 极简文档风
```
纯白背景搭配极细线框和大量留白，层次清晰，干净克制的极简主义风格。
```

### 编号 10 — 科技暗黑风
```
深色背景带蓝紫渐变光效，卡片有半透明玻璃质感，关键数字带霓虹发光效果。
```

### 编号 11 — 玻璃拟态风
```
半透明磨砂玻璃卡片搭配渐变紫蓝背景和柔和光晕，高端现代的视觉质感。
```

### 编号 12 — 赛博朋克风
```
暗黑城市背景搭配霓虹粉绿色系和故障艺术效果，充满科幻未来感和视觉冲击力。
```

### 编号 13 — 等轴测城市风
```
城市建筑等距俯视视角搭配3D场景感和明亮配色，充满空间层次的立体信息图。
```

### 编号 14 — 复古手绘风
```
旧纸张米黄底色搭配手绘线条和复古棕褐色调，历史感和手工温度兼备。
```

### 编号 15 — 扁平插图风
```
明快几何色块搭配简洁扁平图标和现代感，清爽利落的互联网插图风格。
```

### 编号 16 — 自然生态风
```
写实植物动物插画搭配自然绿棕色调和手绘质感，充满生命力的自然科普风格。
```

### 编号 17 — 超现实艺术风
