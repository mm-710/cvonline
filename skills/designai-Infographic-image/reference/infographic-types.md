# 信息图类型详解与选型指南

## 选型决策树

```
内容有时间顺序/阶段?
  ├── 是 → 时间轴型
  └── 否 → 有多对象横向比较?
              ├── 是 → 对比型
              └── 否 → 以数字/比例为核心?
                          ├── 是（大量数据）→ 数据仪表盘型
                          ├── 是（少数KPI）→ 数字焦点型
                          └── 否 → 有流程/步骤?
                                      ├── 是 → 流程图型
                                      └── 否 → 有层级/分类?
                                                  ├── 是 → 层级树型
                                                  └── 否 → 有节点关系?
                                                              ├── 是 → 关系网络型
                                                              └── 否 → 知识/观点类?
                                                                          ├── 是 → 知识卡片型
                                                                          └── 否 → 综合信息图型
```

---

## 类型1：时间轴型 (Timeline)

**适用场景**：历史演进、产品路线图、项目里程碑、技术发展史

**内容特征**：
- 有明确的时间戳（年份/季度/月份）
- 有阶段划分（Phase 1/2/3）
- 强调"从...到..."的演变

**视觉结构**：
- 横向时间轴（适合 16:9）
- 竖向时间轴（适合 9:16 或 4:3）
- 节点+描述的经典形式
- 重要节点放大显示

**提示词关键词**：`timeline infographic`, `horizontal timeline`, `milestone visualization`, `chronological flow`

**内容整理模板**：
```
时间点1（年份/阶段）→ 核心事件/成就（1-2句话，含数据）
时间点2 → ...
时间点N → ...（当前/未来）
```

---

## 类型2：对比型 (Comparison)

**适用场景**：方案对比、产品对比、技术选型、Before/After对比

**内容特征**：
- 有2-5个对象需要横向比较
- 有明确的对比维度（价格/功能/性能）
- 目标是帮助决策

**视觉结构**：
- 表格式对比（维度×对象的矩阵）
- 雷达图（多维度综合展示）
- 双栏对比（Before vs After）
- 优劣势并列卡片

**提示词关键词**：`comparison chart`, `versus infographic`, `feature matrix`, `pros and cons`

**内容整理模板**：
```
对比维度 | 方案A | 方案B | 方案C
维度1   |  数据 |  数据 |  数据
维度2   |  数据 |  数据 |  数据
推荐：方案X（原因）
```

---

## 类型3：数据仪表盘型 (Data Dashboard)

**适用场景**：年度报告、业务总结、KPI汇报、市场数据展示

**内容特征**：
- 有大量数字、百分比、同比/环比
- 有多个指标需要同时展示
- 强调数据的视觉冲击力

**视觉结构**：
- 多个大数字卡片（重点指标用超大字号）
- 条形图/折线图/饼图
- 进度条/仪表盘
- 区域色块区分不同指标类别

**提示词关键词**：`data dashboard`, `KPI infographic`, `metrics visualization`, `data cards`

**内容整理模板**：
```
核心指标（最多6个，每个含数字+趋势）：
- 指标名：数值 ↑↓变化%
图表数据（如有）：
- 图表类型：数据系列
趋势描述：...
```

---

## 类型4：流程图型 (Process Flow)

**适用场景**：操作流程、工作流、审批链、系统架构、决策树

**内容特征**：
- 有明确的步骤顺序（Step 1→2→3）
- 有条件判断/分支
- 有起点和终点

**视觉结构**：
- 横向流程箭头（适合 16:9）
- 竖向流程（适合 9:16）
- 泳道图（多角色流程）
- 决策菱形节点

**提示词关键词**：`process flow`, `workflow diagram`, `step-by-step infographic`, `flowchart`

**内容整理模板**：
```
开始 → 步骤1（描述）→ 步骤2 → [判断：条件A→步骤3A, 条件B→步骤3B] → 结束
```

---

## 类型5：层级树型 (Hierarchy)

**适用场景**：组织架构、分类体系、知识框架、产品功能树

**内容特征**：
- 有明确的父子关系
- 有多级分类（最多4级）
- 强调"属于"的包含关系

**视觉结构**：
- 思维导图（放射状）
- 树形图（从上到下）
- 矩形树图（Treemap）
- 嵌套圆形（Sunburst）

**提示词关键词**：`hierarchy chart`, `org chart`, `mind map`, `tree diagram`, `knowledge map`

**内容整理模板**：
```
根节点
├── 一级节点A
│   ├── 二级节点A1
│   └── 二级节点A2
├── 一级节点B
└── 一级节点C
```

---

## 类型6：关系网络型 (Network/Ecosystem)

**适用场景**：生态系统、技术栈关系、概念关联、影响因素图

**内容特征**：
- 多个节点之间有相互关联
- 关系是双向的或网状的
- 没有严格的层级结构

**视觉结构**：
- 中心节点+卫星节点
- 网络拓扑图
- 六边形蜂窝布局
- 模块化分组展示

**提示词关键词**：`ecosystem map`, `network diagram`, `relationship web`, `interconnected nodes`

**内容整理模板**：
```
中心概念：{核心}
关联节点：A, B, C, D
关系说明：A与B的关系、B与C的关系...
分组：{分类1: A,B} {分类2: C,D}
```

## 类型7：数字焦点型 (Number-Focused)

**适用场景**：统计报告摘要、核心成就展示、重点数字强调

**内容特征**：
- 只有3-6个关键数字
- 数字本身就是最重要的信息
- 需要强视觉冲击力

**视觉结构**：
- 超大字号数字（中央焦点）
- 数字配辅助图标
- 简洁的标签说明
- 大量留白突出数字

**提示词关键词**：`number spotlight`, `big data infographic`, `statistics card`, `impact numbers`

---

## 类型8：知识卡片型 (Knowledge Card)

**适用场景**：科普知识、观点传达、定义解释、How-to指南

**内容特征**：
- 以文字为主，图像为辅
- 核心是传达知识/观点而非数据
- 内容精炼，适合单页阅读

**视觉结构**：
- 标题+要点列表
- Q&A格式
- 图文混排
- 章节卡片组合

**提示词关键词**：`knowledge card`, `tips infographic`, `explainer visual`, `educational poster`

---

## 类型9：综合信息图型 (Editorial Infographic)

**适用场景**：研究报告、行业分析、复杂主题的综合展示

**内容特征**：
- 内容量大，涵盖多种子类型
- 有图表、有流程、有数据
- 需要完整的叙事结构

**视觉结构**：
- 分区块的多类型组合
- 顶部标题区 + 中部主内容 + 底部结论区
- 适合 9:16 竖版单页信息图

**提示词关键词**：`editorial infographic`, `magazine-style infographic`, `comprehensive visual`, `full-page infographic`

## 宽高比建议

| 类型 | 推荐比例 | 备注 |
|------|---------|------|
| 时间轴型（横向） | 16:9 | 适合横向展示 |
| 时间轴型（纵向） | 9:16 | 适合手机/竖屏 |
| 对比型 | 16:9 | 表格式对比 |
| 数据仪表盘型 | 16:9 | 多图表并排 |
| 流程图型 | 16:9 | 水平流程 |
| 层级树型 | 4:3 | 树形结构 |
| 关系网络型 | 1:1 | 中心辐射 |
| 数字焦点型 | 1:1 | 方形聚焦 |
| 知识卡片型 | 9:16 | 竖版阅读 |
| 综合信息图型 | 9:16 | 完整信息页 |
