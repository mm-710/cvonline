**💡 可选：自定义宽高比**
- 直接输入编号：使用该风格 + 推荐宽高比
- 输入「宽高比 + 编号」：例如 `9:16 + 10` 可同时指定宽高比和风格
- 支持宽高比：`16:9` / `4:3` / `3:2` / `21:9` / `1:1` / `4:5` / `2:3` / `3:4` / `9:16`

**输入示例**：
- `1` → 系统自动匹配风格 + 推荐宽高比
- `10` → 科技暗黑风 + 推荐宽高比
- `9:16 + 12` → 赛博朋克风 + 9:16 竖版
- 不输入 → 默认选项1，立即开始生图

## 阶段4：脚本 JSON 输出格式

**成功上传 CDN 时**：
```json
{
  "success": true,
  "image_url": "https://design-out.staging.kuaishou.com/xxx.jpg",
  "mode": "TEXT_TO_IMAGE",
  "usageInfo": {"totalTokenCount": 1234}
}
```

**CDN 上传失败降级时**：
```json
{
  "success": true,
  "data_url": "data:image/jpeg;base64,/9j/4AAQ...",
  "mime_type": "image/jpeg",
  "mode": "TEXT_TO_IMAGE"
}
```

**SSO 健康检查触发条件**：若上一次脚本调用返回以下任一情况，**必须先重新登录再执行脚本**：
- `success: false` 且 `message` 包含 `401`、`403`、`SSO`、`cookie`、`认证`、`过期`、`Unauthorized`
- 脚本进程退出码非 0 且 stderr 含上述关键词

## 阶段5：渲染输出模板

**文生图输出格式**：
```markdown
**Route A — 叙事流版本**

![Route A](https://design-out.staging.kuaishou.com/route-a.jpg)

**Route B — 风格矩阵版本**

![Route B](https://design-out.staging.kuaishou.com/route-b.jpg)

| 参数 | Route A | Route B |
|------|---------|---------|
| 宽高比 | {aspectRatio} | {aspectRatio} |
| 分辨率 | 2K | 2K |
| 模式 | {mode} | {mode} |

💡 请选择你喜欢的版本，或告诉我需要调整的地方。
```

⚠️ **关键要求**：图片 Markdown 必须在同一行，`]` 和 `(` 之间绝对不能有换行或空格。

**示例（完整流程）**：
```
1. 脚本输出：{"success": true, "image_url": "https://design-out.staging.kuaishou.com/abc123.jpg"}
2. 提取 URL：https://design-out.staging.kuaishou.com/abc123.jpg
3. 渲染为：![Route A](https://design-out.staging.kuaishou.com/abc123.jpg)
```

**图生图输出格式**：
```markdown
**✅ 图片编辑完成！**

![编辑后的图片](https://design-out.staging.kuaishou.com/edited.jpg)

| 参数 | 值 |
|------|----|
| 模式 | IMAGE_TO_IMAGE |
| 输出路径 | output/edited.jpg |
```
