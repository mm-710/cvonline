# 案例：AI Skill 生态系统信息图（v3.2 叙事流写法）

**版本**：v3.2  
**难度**：⭐⭐ 中等（结构清晰的关系网络内容）  
**用户风格选择**：10 — 科技暗黑风  
**宽高比**：16:9

---

## 输入材料

```markdown
# AI Skill 生态规划

## 核心模块
- 图像生成（ai-image-generator）
- 信息图生成（infographic-generator）
- PPT生成（ppt-from-vision）
- 漫画生成（baoyu-comic）
- 体验地图（experience-map-b2b）

## 技术依赖
- 所有模块共用 DesignAI API（workflow 631）
- 图像模型：GeminiMultiImageAdvancedV2
- 输出格式：JPG/PNG

## 用户规模
- 当前用户：1200人
- 月活：450人
- 日均生成图片：86张
```

## v3.2 写法要点（对比旧版）

| 维度 | ❌ 旧写法 | ✅ v3.2 新写法 |
|------|----------|--------------|
| 内容组织 | `【具体内容】`、`【画面布局】` 区块标题 | 连续叙述段落，无区块标题 |
| 布局指令 | `中央区域：中心核心节点 + 放射状5个子节点` | 不指定布局结构，信任模型 |
| 风格写法 | hex颜色值 `#0A0A1A`、`#4F46E5 → #7C3AED` | 路线B只用一句氛围描述词 |
| 图表类型 | `渐变光效虚线（蓝色发光）` 等具体图形指令 | 不预设视觉形式 |
| 双路线 | 只有一份提示词 | 路线A自由 + 路线B风格引导，并行生成 |
| 金句 | 无 | 正文末尾融入一句情感收尾金句 |
